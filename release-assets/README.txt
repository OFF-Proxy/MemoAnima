=====================================================
 メモアニマ (MemoAnima) v1.1.0
 3DSのお絵かきアニメ作品をPCで楽しむファンツール
=====================================================

■ メモアニマとは
ニンテンドー3DSで作ったお絵かきアニメ作品（.kwz / .ppm）をPCに取り込み、
編集して、MP4 / GIF / APNG / PNG連番に書き出せる Windows 用ツールです。
・非公式・非営利の個人製作ファンツールです
・利用者ご自身が作成した作品データを、ご自身のPCで編集するためのツールです
・SDカードなど取り込み元のデータは「読み取りのみ」。書き込み・変更は一切しません
・編集はPC内ライブラリへの独立コピーに対して行います

■ v1.1.0 で増えたこと
・文字入れの書体が5種類から選べるようになりました
・絵をぐにゃっと歪ませる道具（押す／ふくらませる／へこませる／四隅をつまむ）
・1コマから「少し揺れた絵」を数枚まとめて作る「ゆらゆら」

■ 動作環境
・Windows 10 / 11（64bit）
・Microsoft Edge WebView2 ランタイム
  （Windows 10/11 には通常搭載されています。無い場合は起動時に案内が出ます。
    Microsoft の WebView2 配布ページから Evergreen ブートストラップを
    インストールしてください。本アプリが自動ダウンロードすることはありません）

■ はじめかた
1. この zip を好きな場所に解凍する（例: デスクトップや D:\Tools など）
2. MemoAnima.exe をダブルクリックして起動
3. 初回ガイドに沿って、ライブラリフォルダの設定 → 作品の取り込み → 編集 → 書き出し
※ レイヤーは全ページ共通です（アニメ制作ツールの標準的な方式）。
　 ページを追加すると、同じレイヤー構成の白紙ページができます。

■ SmartScreen の警告が出た場合
個人配布の署名なしアプリのため、初回起動時に Windows SmartScreen の
「WindowsによってPCが保護されました」という青い画面が出ることがあります。
これはウイルス検出ではなく「発行元が未確認」という意味の警告です。
実行するには:
  「詳細情報」をクリック →「実行」ボタンをクリック
（心配な場合は、お手元のウイルス対策ソフトでスキャンしてからご利用ください）

■ 通信について
本アプリはインターネット通信を一切行いません（更新チェック・送信機能もありません）。
動画変換エンジン（ffmpeg.wasm）も同梱されており、オフラインで完結します。

■ データの保存場所
・作品ライブラリ: 初回ガイドで自分で選んだフォルダ
・設定・自動保存: %APPDATA%\com.arcana.memoanima
アンインストールは、解凍したフォルダと上記フォルダを削除するだけです。

=====================================================
 メモアニマ (MemoAnima) v1.4.1
 3DSのお絵かきアニメ作品をPCで楽しむファンツール
=====================================================

■ メモアニマとは
ニンテンドー3DSで作ったお絵かきアニメ作品（.kwz / .ppm）をPCに取り込み、
編集して、MP4 / GIF / APNG / PNG連番に書き出せる Windows 用ツールです。
・非公式・非営利の個人製作ファンツールです
・利用者ご自身が作成した作品データを、ご自身のPCで編集するためのツールです
・SDカードなど取り込み元のデータは「読み取りのみ」。書き込み・変更は一切しません
・編集はPC内ライブラリへの独立コピーに対して行います

■ v1.4.1 で増えたこと
・アプリ内アップデートの配信経路を、実際の配布物で確認してからの公開版です。
　機能は下の v1.4.0 と同じです

■ v1.3.0 で増えたこと・直したこと
このバージョンは中身が2つあります。5言語対応と、v1.2.0 のあとに積み上げた
12本ぶんの機能追加・修正です（v1.2.1 として出す予定だったものをまとめました）。

＜言語＞
・5言語に対応しました（日本語／英語／スペイン語／ポルトガル語（ブラジル）
　／韓国語）。初回は Windows の表示言語に合わせて開き、⚙ からいつでも
　変えられます。切り替えると再起動なしですぐ反映されます
・新しく作るアルバム名・レイヤー名は、作った時の言語で付きます
　（すでにある名前は書き換わりません）

＜描く＞
・クリッピング：レイヤーを、すぐ下のレイヤーの描いてある所だけに表示します
　（レイヤー行の ⤵ で切り替え）
・線を太らせる／細らせる（1ドット）。選択範囲があれば範囲内だけ
・レイヤーのコピー＆ペースト。全コマへの一括貼り付けもできます
　（ロゴやサインを入れるときに）
・紙の色に「透明」を追加。APNG・PNG連番では透過のまま書き出せます
・既定のパレットを6色（黒・白・赤・青・黄・緑）に。以前の14色は
　「レトロ14色」として残っています
・かすり消し（トーン柄で消す）とトーンの柄5つを追加
・編集中のカーソルを選べます（点／十字／矢印）。いま置いたら塗られる範囲を
　示す輪と、カーソルが乗っている1ドットの枠は、それぞれ切り替えられます。
　「十字」を選ぶと以前とまったく同じ見た目に戻ります

＜画面＞
・道具列・右パネル・タイムラインの境目をドラッグして大きさを変えられます
　（ダブルクリックで既定に戻る・配置は保存されます）
・パネルを1つずつ畳めます。⛶ で3つまとめて畳んでキャンバスだけにもできます
・ミニプレビューをタイムラインに収納できます（キャンバスに重なりません・既定）。
　浮かせる／表示しない も選べます
・描いている間はまわりの表示が薄くなります（手を止めれば戻ります）
・ホーム画面で ←→ とボタンでコマ送りできます

＜書き出し＞
・倍率が ×1／×2／×4／×8 になり、既定が ×4 になりました
　（×1 のまま SNS に上げると画質が乱れる報告が多かったためです）。
　選んでいる倍率の寸法と用途を常に表示します
・書き出した色が本来より濁っていた問題を直しました
　（MP4 の色空間の明示・PNG/APNG への sRGB 情報の付加。画素の値は変えていません）
・GIF の色化けとチラつきを直しました（256色以下の作品は元の色と完全に一致します）
・大きな書き出しの前に、推定メモリ・推定時間・1段下の倍率の見込みを出して
　確認します（禁止はしません）。実行中は残り時間の目安も出ます

＜直したこと＞
・変形の回転が枠の内側にも効いていて、小さい枠だと中を掴んでも回転してしまい
　移動できなかった問題（回転は枠の外側12ドット以内だけになりました）
・手のひら・変形のカーソルが、キャンバスの上では出ていなかった問題
　（以前からの不具合です）
・編集中に F5 / Ctrl+R を押したとき、確認ダイアログが出るようになりました
　（未保存の変更があるときだけ）
・「別名で保存」の初期選択が「最後に使ったアルバム」だった問題。
　これからは、その作品自身が入っているアルバムが選ばれます
・選択範囲を消したあと、選択が解除されてしまっていた問題
・タイムラインの見出しが2行になって帯が高くなっていた問題
・画像取り込みのパレット名を「クラシック6色」に変えました

＜使うときの注意＞
・クリッピングを使った作品を旧バージョン（v1.2.0 以前）で開くと、はみ出しが
　見えます。データは壊れませんし、v1.3.0 で開き直せば元どおりです
・書き出しは ×4 がおすすめです。GIF の ×8 は数十MBになるので、SNS には
　×4 か MP4 をお使いください

※作品データの形式は変わっていません。これまでに作った作品はそのまま
　開けます。設定とショートカットの割り当ても引き継がれます。

※英語版の説明は同梱の README_en.txt をご覧ください。
　(English: see README_en.txt in this folder.)

■ はじめかた
1. この zip を好きな場所に解凍する（例: デスクトップや D:\Tools など）
2. MemoAnima.exe をダブルクリックして起動
3. 初回ガイドに沿って、ライブラリフォルダの設定 → 作品の取り込み → 編集 → 書き出し
※ インストーラ版（MemoAnima_1.4.1_x64-setup.exe）もあります。そちらは
　 ダブルクリックするだけで入り、管理者権限も要りません。
　 ★このポータブル版（zip）は、その場で上書き更新はできません。
　 更新を選ぶとインストーラ版が新しく入ります（下の「■ 通信について」参照）。
　 ポータブル版からインストーラ版へ移っても、作品ライブラリ・設定・自動保存は
　 そのまま引き継がれます（保存場所が同じためです）。
※ レイヤーは全ページ共通です（アニメ制作ツールの標準的な方式）。
　 ページを追加すると、同じレイヤー構成の白紙ページができます。

■ SmartScreen の警告が出た場合
個人配布の署名なしアプリのため、初回起動時に Windows SmartScreen の
「WindowsによってPCが保護されました」という青い画面が出ることがあります。
これはウイルス検出ではなく「発行元が未確認」という意味の警告です。
実行するには:
  「詳細情報」をクリック →「実行」ボタンをクリック
（心配な場合は、お手元のウイルス対策ソフトでスキャンしてからご利用ください）

※この警告は、新しい版に更新するときにも出ることがあります。署名を付けていない
　ソフトは、ファイルが変わるたびに「初めて見るファイル」として扱われるためです。
　毎回同じ手順（「詳細情報」→「実行」）で進めていただけます。

■ 通信について
描画・編集・書き出しは、お手元の端末だけで完結します。インターネットに
繋がっていなくても、すべての機能が使えます。
動画変換エンジン（ffmpeg.wasm）も同梱されており、オフラインで完結します。

このバージョンでアプリが自分から通信するのは、
「新しい版が出ているかどうかの確認」の1つだけです。
・確認するのは起動時に一度だけです。決まったアドレスから「最新版はどれか」を書いた
　小さなファイルを読むだけで、あなたの情報を送ることはありません
　（新しいかどうかの判断は、お手元のアプリの中で行っています）
・⚙ からいつでもオフにできます。オフにしても、ほかの機能はまったく制限されません
・見つかっても、勝手にダウンロードはしません。押していただいてから落とします
・通信できないときは、何も表示せずにそのまま使えます
・★このポータブル版（zip）は、その場で上書き更新はできません。「今すぐ更新」を
　押すとインストーラ版が新しく入り、この zip のほうは古いまま残ります。
　以後はインストーラ版をお使いください（作品ライブラリ・設定・自動保存は
　そのまま引き継がれます。zip のフォルダはあとで削除して構いません）

あなたが投稿を選んだ作品を除き、作品データが外部へ送られることはありません。
どの機能をどれだけ使ったかという記録を、作者が集めることもありません。
この方針は、今後どのバージョン・どの機種でも変わりません。

■ データの保存場所
・作品ライブラリ: 初回ガイドで自分で選んだフォルダ
・設定・自動保存: %APPDATA%\com.arcana.memoanima
・インストーラ版のプログラム本体: %LOCALAPPDATA%\MemoAnima

アンインストールしても、作品ライブラリと設定・自動保存は消えません。
・ポータブル版: 解凍したフォルダを削除するだけです
・インストーラ版: Windows の「アプリと機能」から削除できます
どちらも、作品を完全に消したいときは上記のフォルダを自分で削除してください。

=====================================================
 メモアニマ (MemoAnima) v1.7.0
 3DSのお絵かきアニメ作品をPCで楽しむファンツール
=====================================================

■ メモアニマとは
ニンテンドー3DSで作ったお絵かきアニメ作品（.kwz / .ppm）をPCに取り込み、
編集して、MP4 / GIF / APNG / PNG連番に書き出せる Windows 用ツールです。
・非公式・非営利の個人製作ファンツールです
・利用者ご自身が作成した作品データを、ご自身のPCで編集するためのツールです
・SDカードなど取り込み元のデータは「読み取りのみ」。書き込み・変更は一切しません
・編集はPC内ライブラリへの独立コピーに対して行います

■ v1.7.0 で変わったこと
・【オニオンスキン（透かし表示）に「向き」が付きました】前のコマだけ・次のコマだけ・
　両方から選べます。前後が同時に出てごちゃつく場面で、見たいほうだけ残せます。
　既定は「両方」で、v1.6.0 までとまったく同じ見え方です
・【そのオニオンスキンを見つけやすい場所へ移しました】右パネルのいちばん上です。
　これまでは下のほうにあり、画面が狭いとスクロールしないと出てきませんでした
・【よく使う色を登録しておける棚が付きました】最大48色。フルカラーで作品の色が
　増えても、自分で選んだ色だけをすぐ出せます。登録した色はアプリを閉じても、
　別の作品を開いても残ります
・【コマを「まとめて追加」できるようになりました】1〜100枚を一度に足せます
　（今のコマの複製も選べます）。取り消しは一回で全部戻ります
・【「マイ柄」が、登録前から見えるようになりました】これまでは1つも登録していないと
　項目そのものが出ておらず、機能があること自体が分かりませんでした。あわせて
　「かすり消し」にも、何ができるかの説明を画面に出しています
・【ショートカットキー設定の手数を減らしました】組み込みの組み合わせのまま「変更」を
　押せます（あなた用の組み合わせが自動で作られます）
・【Ctrl / Shift / Alt を「タップ」にも割り当てられます】単独で押してすぐ離す操作です。
　ペンタブレットのサイドスイッチが修飾キーを送る設定のときに使えます
　（長押しや他のキーとの組み合わせは、これまでどおりです）
・【大きな作品を扱うときの安定性を上げました】コマを大量に貼り付けても落ちなく
　なりました。時間のかかる操作の最中は「◯◯しています」と出て、二重に押せない
　ようにしています。入りきらないときは「あと約◯コマ」と先に知らせます
・【とても大きな作品で保存が失敗することがあったのを直しました】たくさん貼り付けた
　直後などに起きていました。保存の前に片づけを待つ場合は、右下にその旨が出ます
　（その間も描き続けられます）。あわせて、書き出しの前に全コマを一度に展開して
　いたのをやめ、1コマずつ読むようにしました
・【同じ修飾キーの取り合いを断るようにしました】「タップ」と「＋クリック」の両方に
　同じキーを割り当てようとすると、理由つきでお断りします（ペンを置いたときに
　取り合いになるためです）。すでに両方に割り当ててある場合は、設定画面に印が
　出ます。スポイトで色を拾ったときは短く知らせます
・表示・設定・入力と、安定性の更新です。作品のファイルは何も変わりません
　（v1.6.0 で保存したものと同じ形式のままです）

■ v1.6.0 で変わったこと
・【開く・保存が桁違いに速くなりました】作品の保存形式を新しくしました
　（拡張子は .memoanima のまま・中身の入れ物だけ変わります）。大きい作品ほど
　効きます: 1,000コマ級の実測で、開くのが 約20秒 → 約3秒。保存も速くなったうえ、
　保存している間も描き続けられます。ファイルの大きさも3割ほど小さくなりました。
　小さい作品はこれまでと同じ感覚のままです
・【⚠ 大事な注意】この版で保存した作品は、v1.5系以前のメモアニマでは開けません
　（開こうとすると「このファイルは新しいバージョン（v6）で作られています」と出ます）。
　また、この版から前の版に戻すと、オートセーブの控えも読めなくなります。
　これまでの作品（旧形式）は、今までどおり全部開けます——開くだけなら
　ファイルは書き換わりません（保存したときに新形式になります）
・【旧形式でも保存できます】以前の版の人に作品ファイルを渡すときは、保存先を選ぶ
　画面にある「以前のバージョン（v1.5系）でも開ける形式で保存する」にチェックを
　入れてください。その保存先には、次からも同じ形式で保存されます

■ v1.5.10 で変わったこと
・【保存中も描き続けられるようになりました】これまで、大きい作品の保存中は画面に
　「保存中です」が出て、終わるまで何もできませんでした（大きい作品では数十秒）。
　いまは保存を押した瞬間の絵がそのまま保存され、その間もふつうに描き続けられます。
　保存中は右下に小さく「保存しています…」と出ます。
　※ 保存されるのは「保存を押した瞬間まで」の絵です。保存中に描いた分は、
　　 もう一度保存すると入ります（保存中に押した分は、終わってから自動でもう一度保存されます）
・【保存が速くなりました】大きい作品の保存にかかる時間が大きく縮みました。
　そのぶんファイルが少しだけ（1割ほど）大きくなりますが、古い版のメモアニマでも
　これまでどおり開けます
・アプリを閉じるときや書き出しを始めるときに保存が終わっていない場合は、
　「保存が終わるまでお待ちください」と出て、終わってから進みます

■ v1.5.7 で増えたこと・直したこと
・【レイヤーのロック 🔒】レイヤーの行に 🔒 が付きました。ロックすると、そのレイヤーには
　描けなくなります（下描きや背景を守るため）。うっかり描こうとしたときは、絵は変わらずに
　「ロック中です」とお知らせします。フォルダにも 🔒 が付けられて、中のレイヤー全部を
　まとめて守れます。表示の切り替え・名前・並べ替え・不透明度・色の変更・ロック解除は、
　ロック中でもこれまでどおりできます
・【レイヤーの色をコマごとに変えられます】これまではレイヤーの色を変えると全部のコマが
　変わりましたが、タイムラインで選んだコマだけに色を付けられるようになりました。
　色チップを押すと「このコマだけ」「選んだ ◯ コマ」「全コマ」から選べます。
　色を付けたコマには、タイムラインに細い色の帯が出ます。絵そのものは変わらないので、
　外せば元どおりです（ご要望をいただいて作りました）
・【再生の音ズレを直しました】ライブラリで作品を再生したとき、最初の1周だけ音が
　絵より遅れて始まることがありました。音の準備ができてから再生を始めるようにしたので、
　1周目からそろいます（ご報告をいただいて直しました）
・表示言語の選び方の画面で、2行目のボタンだけが横に長く伸びていたのを直しました
■ v1.5.6 で変わったこと
・【大きな作品が軽くなりました】たくさんのコマとレイヤーで作った作品を開いたあと、
　見えていないコマを自動でしまっておくようにしました。1,000コマを超える作品で、
　絵のデータが占めるぶんはおよそ 20 分の1、アプリ全体で使う量も 5 分の1 ほどに
　なります（実測: 1.9GB → 0.4GB）。絵は 1 ドットも変わりません。
　しまう作業は開いたあとに少しずつ進むので、開く速さは変わりません
・50コマくらいまでの作品では、これまでとまったく同じ動きです（何も変わりません）
・遠くのコマへ飛ぶときに、ほんの一瞬だけ間が空くことがあります（前のコマが出たまま
　待ちます。真っ白にはなりません）
・「元に戻す」で戻れる回数を 64 回から 200 回に増やしました。作品が大きいときは
　メモリに合わせて自動で少なくなります
・右パネルのメモリ表示に「実際に使っている量」の行が増えました（大きな作品のみ）
・作品を閉じてライブラリに戻ったとき、その作品の「元に戻す」のぶんを片づけるように
　しました（これまで次の作品を開くまで残っていました）
・作品を開くとき、コマの数が合っているかを別のやり方でもう一度数えて確かめるように
　しました。合わないときは開かずに知らせます（黙って 1 コマ減ることを防ぎます）

　（重い作品で保存ボタンを何度も押すと、そのぶんメモリを使って落ちていました）
・⚙ に「ログのフォルダを開く」を追加しました。うまく動かないときに送っていただく
　記録で、作品や名前は入りません（1MBを超えたら古いほうから捨てます）
・右パネルに「メモリの使用量」を表示するようにしました（作品／元に戻す／合計）。
　大きくなってきたら、保存や作品を分けることをおすすめする案内が出ます
　（作業は止めません）
・色が256色を超えて高精細モードに切り替わるとき、大きな作品では使用量を
　お知らせするようにしました（この切り替えは元に戻せません）
・とても大きな作品では、元に戻せる回数が自動で少なくなります。メモリを
　使い切って落ちるのを防ぐためです（小さな作品ではこれまでどおりです）
・作品を削除したとき、控えや保存途中のファイルも一緒に片づけるようにしました
・ウィンドウの横幅が足りないとき、右上の ⚙（設定）が画面の外へ押し出されて
　押せなくなることがある不具合を直しました（検索バーが先に縮むようになります）
・ウィンドウに最小サイズ（900×540）を設けました
・ショートカットに「⚙ 設定を開く」を追加しました（既定 Ctrl+, ・ホーム画面用）。
　⚙ が押せない状況でも設定を開けます
・上書き保存のとき、1つ前の内容を控えとして残すようになりました。そのぶん
　ライブラリフォルダの使用量が最大で2倍になります（⚙ にも記載）

　／韓国語）。初回は Windows の表示言語に合わせて開き、⚙ からいつでも

・新しく作るアルバム名・レイヤー名は、作った時の言語で付きます
　（すでにある名前は書き換わりません）

＜描く＞
・クリッピング：レイヤーを、すぐ下のレイヤーの描いてある所だけに表示します
　（レイヤー行の ⤵ で切り替え）
・線を太らせる／細らせる（1ドット）。選択範囲があれば範囲内だけ
・レイヤーのコピー＆ペースト。全コマへの一括貼り付けもできます
　（ロゴやサインを入れるときに）
・紙の色に「透明」を追加。APNG・PNG連番では透過のまま書き出せます
・既定のパレットを6色（黒・白・赤・青・黄・緑）に。以前の14色は
　「レトロ14色」として残っています
・かすり消し（トーン柄で消す）とトーンの柄5つを追加
・編集中のカーソルを選べます（点／十字／矢印）。いま置いたら塗られる範囲を
　示す輪と、カーソルが乗っている1ドットの枠は、それぞれ切り替えられます。
　「十字」を選ぶと以前とまったく同じ見た目に戻ります

＜画面＞
・道具列・右パネル・タイムラインの境目をドラッグして大きさを変えられます
　（ダブルクリックで既定に戻る・配置は保存されます）
・パネルを1つずつ畳めます。⛶ で3つまとめて畳んでキャンバスだけにもできます
・ミニプレビューをタイムラインに収納できます（キャンバスに重なりません・既定）。
　浮かせる／表示しない も選べます
・描いている間はまわりの表示が薄くなります（手を止めれば戻ります）
・ホーム画面で ←→ とボタンでコマ送りできます

＜書き出し＞
・倍率が ×1／×2／×4／×8 になり、既定が ×4 になりました
　（×1 のまま SNS に上げると画質が乱れる報告が多かったためです）。
　選んでいる倍率の寸法と用途を常に表示します
・書き出した色が本来より濁っていた問題を直しました
　（MP4 の色空間の明示・PNG/APNG への sRGB 情報の付加。画素の値は変えていません）
・GIF の色化けとチラつきを直しました（256色以下の作品は元の色と完全に一致します）
・大きな書き出しの前に、推定メモリ・推定時間・1段下の倍率の見込みを出して
　確認します（禁止はしません）。実行中は残り時間の目安も出ます

＜直したこと＞
・変形の回転が枠の内側にも効いていて、小さい枠だと中を掴んでも回転してしまい
　移動できなかった問題（回転は枠の外側12ドット以内だけになりました）
・手のひら・変形のカーソルが、キャンバスの上では出ていなかった問題
　（以前からの不具合です）
・編集中に F5 / Ctrl+R を押したとき、確認ダイアログが出るようになりました
　（未保存の変更があるときだけ）
・「別名で保存」の初期選択が「最後に使ったアルバム」だった問題。
　これからは、その作品自身が入っているアルバムが選ばれます
・選択範囲を消したあと、選択が解除されてしまっていた問題
・タイムラインの見出しが2行になって帯が高くなっていた問題
・画像取り込みのパレット名を「クラシック6色」に変えました

＜使うときの注意＞
・クリッピングを使った作品を旧バージョン（v1.2.0 以前）で開くと、はみ出しが
　見えます。データは壊れませんし、v1.3.0 で開き直せば元どおりです
・書き出しは ×4 がおすすめです。GIF の ×8 は数十MBになるので、SNS には
　×4 か MP4 をお使いください

 1. これは何か
------------------------------------------------------------------

ニンテンドー3DSで作ったお絵かきアニメ作品（.kwz）を
パソコンに取り込み、編集して、MP4 / GIF / APNG / PNG連番 に
書き出せるツールの、**Mac 版**です。

Windows 版 v1.9.0 とまったく同じ中身です。機能も、作品ファイルの
形式も共通なので、Windows で作った作品がそのまま開けます。

v1.9.0 から、Apple の署名と公証（Apple による安全チェック）を
受けています。はじめて開くときに「開発元を確認できません」と
止められることはありません。

Mac で動かした実績はまだ Windows より少ないので、うまくいかない
場面を見つけたら、**報告していただけると本当に助かります。**


------------------------------------------------------------------
 2. 動く環境
------------------------------------------------------------------

・macOS（Apple シリコン / Intel の両対応です。M1・M2・M3 などの
　Mac でも、少し前の Intel の Mac でも動きます）
・空き容量は 200MB ほど＋作品を置くぶん

うまく動かない機種・OS のバージョンがありましたら、それも報告して
いただけると助かります。


------------------------------------------------------------------
 3. インストール
------------------------------------------------------------------

(1) ダウンロードした MemoAnima の .dmg ファイルをダブルクリック
    します。ウインドウが開きます。

(2) 中の「MemoAnima」を、「アプリケーション」フォルダにドラッグして
    コピーします。
    ★ **必ず「アプリケーション」フォルダにコピーしてから使ってください。**
      dmg の中から直接起動しないでください（dmg の中は読み取り専用なので、
      うまく動かないことがあります）。

(3) 「アプリケーション」フォルダを開き、MemoAnima をダブルクリックで
    起動します。
    ※ 初回だけ「インターネットからダウンロードされたアプリです。
      開いてもよろしいですか？」と聞かれます（「Apple によるチェックで
      悪質なソフトウェアは検出されませんでした」と添えてあります）。
      「**開く**」を押してください。
    ※ 以前のテスト版で必要だった「右クリック →『開く』」や、
      ターミナルでの操作は、もう要りません。

(4) 起動できたら、dmg は取り出して（右クリック →「取り出す」）
    捨ててかまいません。


------------------------------------------------------------------
 4. 最初の起動 ― 作品の保存場所を決める
------------------------------------------------------------------

初回は「ようこそ メモアニマへ！」と出て、**作品を保存するフォルダ**
を聞かれます。「フォルダを選ぶ」を押して、好きな場所を指定して
ください（例: 書類 の中に「メモアニマ」という新しいフォルダを作る）。

取り込んだ作品も、新しく描いた作品も、すべてここに入ります。
あとから 設定（右上の歯車のアイコン）で変えられます。

⚠ 「ダウンロード」「デスクトップ」「書類」を選ぶと、macOS が
　 「"MemoAnima" が "ダウンロード" フォルダ内のファイルにアクセス
　 しようとしています」と聞いてくることがあります。**「許可」**を
　 押してください。ここで「許可しない」を選ぶと、作品の読み書きが
　 できなくなります（あとから システム設定 → プライバシーと
　 セキュリティ → ファイルとフォルダ で変えられます）。

 5. ★ ほかのパソコンから作品を持ってくるとき（大事）
------------------------------------------------------------------

Windows のメモアニマで作った作品（.memoanima）を、Google ドライブ
などのクラウドを通して Mac に持ってくると、**ファイル名の末尾に
「.gz」が付いてしまう**ことがあります。

    ○ 正しい名前 : わたしの作品.memoanima
    × 付いた状態 : わたしの作品.memoanima.gz

こうなると、メモアニマからは作品として見えず、**アルバムの中身が
0 件**に見えます。ファイルが消えたわけでも壊れたわけでもありません。
名前を戻せば、そのまま開けます。

これはクラウド側がファイルの中身を見て種類を判断するために起きる
もので、Mac でも Windows でも同じように起こります。


【直し方1】数が少ないとき（Finder で）

  ファイルを右クリック →「名前を変更」で、末尾の「.gz」だけを
  消します。「本当に ".gz" から ".memoanima" に変更しますか？」と
  聞かれたら「**.memoanima を使用**」を選びます。


【直し方2】数が多いとき（ターミナルで一度に）

  「ターミナル」を開き、次のように打ちます。
  1 行目の場所は、ご自分の保存先フォルダに読み替えてください。

      cd ~/Documents/メモアニマ
      find . -name '*.memoanima.gz' | wc -l

  → 何個あるかが表示されます。0 でなければ、次を実行します。

      find . -name '*.memoanima.gz' -exec sh -c 'mv -n "$1" "${1%.gz}"' _ {} \;

  終わったらメモアニマに戻り、ライブラリを開き直してください。
  （※ 同じ名前の作品がすでにある場合は、上書きせず飛ばします）


【こうすると起きません】

  作品をまとめて渡すときは、**ZIP にまとめてから**クラウドに
  上げてください。ZIP の中身は触られないので、名前が変わりません。

 6. ショートカット（⌘ キー）
------------------------------------------------------------------

v1.9.0 から、ショートカットは **⌘（command）キー**で使えます。
画面の説明やショートカットの一覧も ⌘ ⌥ ⇧ の記号で表示されます。

    元に戻す        ⌘ + Z
    やり直す        ⌘ + Shift + Z（または ⌘ + Y）
    コピー          ⌘ + C
    切り取り        ⌘ + X
    貼り付け        ⌘ + V
    保存            ⌘ + S
    別名で保存      ⌘ + Shift + S
    設定を開く      ⌘ + ,（ホーム画面で）

control キーでも同じように動きます（Mac では ⌘ と control を同じ
キーとして扱うので、⌘ と control に別々の命令は割り当てられません）。

そのほかのショートカットは、設定（歯車のアイコン）→ ショートカット
で一覧を見られます。自分の好きなキーに割り当て直すこともできます。

 7. いまの版でできないこと
------------------------------------------------------------------

・**Mac 版は今のところ手動更新です。次の版からアプリ内更新に対応します。**
  いまの版では、新しい版が出てもアプリからは更新できません（設定の
  「更新を確認」を押すと「この環境ではアプリ内の自動更新に対応して
  いません」と出ます）。それまでは、新しい版を下の配布ページから
  ダウンロードして、同じように「アプリケーション」フォルダへ上書き
  コピーしてください。**あなたの作品はそのまま残ります。**

・見た目が Windows 版と少し違うところがあります（並びの余白など）。
  順に直していきます。


------------------------------------------------------------------
 8. うまくいかないとき
------------------------------------------------------------------

■ アプリが開かない
  → 「アプリケーション」フォルダにコピーしてから起動しているか
    確かめてください（上の 3）。dmg の中から直接起動すると、
    うまく動かないことがあります

■ アルバムの中身が 0 件になっている
  → 上の 5（末尾に .gz が付いていないか確かめてください）

■ 作品を取り込めない・読み込めない
  → システム設定 → プライバシーとセキュリティ → ファイルとフォルダ
    を開き、MemoAnima の「ダウンロード」などが**オン**になっているか
    確かめてください。オフだと読み込みに失敗します。

■ 音が出なくなった
  → いったん停止して
    もう一度再生してみてください。それでも戻らない場合は、下の 9 の
    ログを添えて教えていただけると原因を追えます。

■ 動きが重い・固まる
  → コマ数の多い作品では時間がかかることがあります。「読み込み中です」
    が出ている間は、そのままお待ちください。

 9. 不具合の報告のしかた
------------------------------------------------------------------

「動いた」「動かなかった」、どちらの報告も助かります。

  ・X（旧Twitter）  @Arcana_Proxy
  ・配布サイト      https://shitamatsuge.com

報告のときは、次を教えていただけると原因を早く見つけられます。

  ・何をしたら、何が起きたか（画面の写真があると助かります）
  ・お使いの Mac の機種（アップルメニュー →「この Mac について」）
  ・**ログファイル**（下の場所にあります）

【ログの場所】

  Finder を開き、メニューバーの「移動」→「フォルダへ移動…」
  （または shift + command + G）を選んで、次を貼り付けます。

      ~/Library/Application Support/com.arcana.memoanima/logs

  この中の memoanima.log がログです。そのまま添付してください。
  ※ ログには**作品の名前やファイルの場所は書き込まれません。**
    書いてあるのは、操作の名前と数字（何ミリ秒かかったか等）だけです。


------------------------------------------------------------------
 10. アンインストール
------------------------------------------------------------------

「アプリケーション」フォルダの MemoAnima をゴミ箱に入れれば
アンインストールできます。

**あなたの作品は消えません。** 作品は 4 で選んだフォルダに入って
いるので、アプリを消しても残ります。

設定とログまで消したいときは、次のフォルダも削除してください。

      ~/Library/Application Support/com.arcana.memoanima
